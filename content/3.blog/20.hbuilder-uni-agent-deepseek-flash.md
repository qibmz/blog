[uni-agent](https://uniapp.dcloud.net.cn/ai/uni-agent.html) 内置在 [HBuilderX](https://hx.dcloud.net.cn/) 和 [HBuilderV](https://doc.dcloud.net.cn/hbuilderv/) 里。不想用 DCloud 订阅时，可以在设置里切到 **自定义Key**，填自己的模型环境变量。下面以 **DeepSeek Flash** 为例。

[HBuilderV](https://doc.dcloud.net.cn/hbuilderv/) 是基于 VS Code 改的 IDE，专门给 uni-app x 用；[HBuilderX](https://hx.dcloud.net.cn/) 则覆盖 uni-app / uni-app x 等更广的工程。两边的 uni-agent 设置入口一致：聊天视图右上角齿轮。

## 打开 uni-agent

**HBuilderX：** 工具栏最右侧 `AI`，或菜单「视图 → 插件扩展视图 → uni-agent」。快捷键 Windows `Ctrl+Alt+I`，macOS `⌃⌘I`。首次点 `AI` 会安装插件。

**HBuilderV：** 已内置，点右上角 `AI`，快捷键同上。

## 切到自定义 Key

1. 打开 uni-agent 聊天视图。
2. 点右上角 **设置**。
3. **模型选择** 选 **自定义Key**，保存。

只把环境变量填上还不够。不选「自定义Key」时，插件仍走 DCloud 订阅，自定义变量不会生效。

## DeepSeek Flash 环境变量

在设置里的环境变量输入框粘贴（把 `api-key` 换成自己的 [DeepSeek API Key](https://platform.deepseek.com/)）：

```text
# uni-agent 配置
UNI_AGENT_BASE_URL=https://api.deepseek.com
UNI_AGENT_API_KEY=api-key
UNI_AGENT_MODEL=deepseek-flash
UNI_AGENT_SMALL_FAST_MODEL=deepseek-flash
UNI_AGENT_MODEL_CONTEXT_WINDOW=258000
```

`UNI_AGENT_MODEL` 和 `UNI_AGENT_SMALL_FAST_MODEL` 都用 `deepseek-flash`：主对话和小任务同一模型。`UNI_AGENT_MODEL_CONTEXT_WINDOW` 按自定义 Key 声明上下文窗口，这里是 `258000`。

保存后新开一轮对话再试。连不上时对照 [uni-agent 自定义 Key 说明](https://uniapp.dcloud.net.cn/ai/uni-agent.html) 检查 Base URL、Key 和模型名。
