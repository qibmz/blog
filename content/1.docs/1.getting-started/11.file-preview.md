## File Viewer

- [文档](https://doc.file-viewer.app/){target="_blank"}
- [官网](https://file-viewer.app/){target="_blank"}
- [在线 Demo](https://demo.file-viewer.app/){target="_blank"}
- [GitHub](https://github.com/flyfish-dev/file-viewer){target="_blank"}
- 浏览器端、可自托管的多格式文件预览组件；Office / PDF / CAD / 压缩包等本地解析，无需上传到第三方转换服务
- 支持 Vue / React / Web Component 等接入，适合私有附件预览场景

## vue-office

- [GitHub](https://github.com/501351981/vue-office){target="_blank"}
- 支持 Word（.docx）、Excel（.xlsx / .xls）、PDF、PPTX 等 Office 文件预览的 Vue 组件集合
- 兼容 Vue 2 / 3，也可在 React 等非 Vue 框架使用，偏轻量的一站式预览方案
