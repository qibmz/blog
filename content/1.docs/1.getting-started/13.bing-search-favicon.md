# Bing 搜索结果不显示网站图标

## 现象

- 在 **Bing 搜索结果**里，站点旁的 favicon / `.ico` **不显示或空白**
- **直接进入网站**时，浏览器标签页图标正常
- 站点自身 `favicon.ico`、HTML `link rel="icon"` 等配置通常没有问题

这更像是 Bing **结果页侧的图标缓存 / 抓取异常**，不一定是站点挂了。

## 处理

在 [Bing Webmaster Tools](https://www.bing.com/webmasters){target="_blank"} 里走反馈，或**直接发邮件给 Bing Webmaster 客服**，说明：

1. 站点域名  
2. 搜索结果里图标缺失的截图或查询词  
3. 直接打开页面时图标正常  

对方处理后，结果页图标一般会恢复。不必先大改站点图标配置（除非本站本身就加载失败）。

## 备注

- Google / 其他引擎正常，不能说明 Bing 结果页也一定正常  
- 本站已放 `public/favicon.ico` 等静态图标；若直链可访问，优先走客服而非反复改文件
