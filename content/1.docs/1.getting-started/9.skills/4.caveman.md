# Caveman

Caveman 是一个帮助 AI Agent **用更少 Token 完成更多工作**的工具与技能集。它可以压缩 Agent 读取的上下文，也可以让 Agent 用更简洁的方式回答，同时保留代码、命令和错误信息的准确性。

## 核心能力

### 精简 Agent 输出

启用 `/caveman` 后，Agent 会使用简洁、直接的表达方式，减少冗长解释。可以根据需要切换不同强度：

```text
/caveman lite
/caveman full
/caveman ultra
/caveman off
```

### 压缩 Agent 输入

Caveman Proxy 会在每次 Provider 调用前压缩上下文，并保留可恢复的原始内容。不同内容类型会采用不同策略：

- **JSON** — 保留键、结构和错误信息，折叠重复数组
- **日志** — 保留错误、堆栈以及首尾内容，移除无关进度信息
- **代码** — 保留导入、签名和类型，省略不影响理解的函数体
- **Diff** — 保留文件、分块头和变更行
- **搜索结果** — 保留关键命中、诊断和安全相关结果
- **文本与 HTML** — 保留标题、开头、结尾和重要段落

### 压缩命令输出

```bash
caveman shrink -- pnpm test
```

命令输出会被压缩为更易处理的上下文，同时支持恢复原始内容。

## 安装

### 安装输出精简技能

```bash
npx skills add JuliusBrussee/caveman
```

安装后，在支持的 Agent 中输入 `/caveman`，或者让 Agent 自动激活该技能。

### 安装 Caveman Proxy

```bash
npm install -g @caveman-ai/cli && caveman setup --install
caveman claude
```

Proxy 支持 Claude Code、Codex、Gemini CLI、Aider、opencode、Hermes Agent、OpenClaw 和 Pi 等工具。它在本地运行，不需要修改 Agent 自己的配置文件。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `caveman learn` | 分析本地 Agent 历史，找出 Token 消耗来源 |
| `caveman learn implement` | 将优化建议交给 Agent，并逐项确认修改 |
| `caveman explore install` | 使用只读子 Agent 快速定位代码 |
| `caveman mem remember` | 保存可跨会话使用的记忆 |
| `caveman stats` | 查看各类内容的压缩统计 |
| `caveman browse <url>` | 以压缩后的可访问性树浏览网页 |

## 使用场景

- 上下文很长、但有效信息比例较低的 Agent 会话
- 日志、测试输出或搜索结果过于庞大的调试任务
- 希望减少回复长度，同时保持技术内容精确
- 想分析真实 Agent 历史中的 Token 浪费位置

> 注意：Caveman 的收益取决于工作负载。对于本身已经非常简短的任务，额外的技能上下文可能抵消部分节省；建议使用 `caveman stats` 或基准测试验证实际效果。
